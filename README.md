# 🚗 Parking Lot System

This is a Parking Lot System developed with a strong focus on clean design and scalable architecture. It showcases the use of essential object-oriented design patterns and principles to build a modular and maintainable parking solution.

## 🔧 Design Patterns & Principles Used

### ✅ Singleton Design Pattern
- Ensures that a single instance of the parking lot manager exists throughout the application lifecycle.
- Helps in central management of parking slots and vehicle entries.

### ✅ Strategy Design Pattern
- Allows runtime selection of parking strategies (e.g., nearest slot, priority-based, etc.).
- Enhances flexibility and adheres to the Open/Closed principle.

### ✅ SOLID Principles
- **S**ingle Responsibility: Each class handles a specific responsibility.
- **O**pen/Closed: Code is open for extension but closed for modification.
- **L**iskov Substitution: Subtypes can replace parent types without breaking the application.
- **I**nterface Segregation: Clients are not forced to depend on unused interfaces.
- **D**ependency Inversion: High-level modules depend on abstractions, not on concrete implementations.
